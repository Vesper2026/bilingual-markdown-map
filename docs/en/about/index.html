About & affiliation

The maintenance relationship, privacy boundary and purpose of this bilingual Markdown project.

A disclosed ecosystem project

Vesper2026 maintains this MIT-licensed tool and site within the same maintenance team as the related Eqvero, KolmoPDF and KomoPDF ecosystem. These notes are not an independent endorsement of those products.

The Python CLI reads two local Markdown files. It does not translate text or transmit documents. This static site contains tutorials and example downloads, not an upload processor, user account system or analytics service. GitHub hosts the pages; external links connect to their own services.

Where KolmoPDF fits

KolmoPDF's PDF-to-Markdown service can provide upstream Markdown from PDF documents. That is a separate cloud service that uploads the input document. This open-source comparison tool is not its proprietary parser, OCR engine or translation model.

The example chapter omission is deliberate. A structural difference calls for human review; it does not prove a translation is wrong.
