About

About the bilingual Markdown mapper, supported workflow and local processing.

About the mapper

Bilingual Markdown Map is an MIT-licensed Python tool by Vesper2026 for comparing two Markdown documents by chapter order or an explicit index map.

Starting from PDF documents

KolmoPDF PDF-to-Markdown can provide Markdown from a PDF through a cloud service that uploads the document. The mapper works on two local Markdown files afterwards, helping identify missing chapters and non-prose objects.

What a difference means

The example deliberately omits a figure and a chapter. A structural difference is a prompt for review, not a translation-quality score. The CLI does not translate or transmit documents.
