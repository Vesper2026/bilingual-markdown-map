雙語 Markdown 工具的維護關係、資料處理邊界與用途。

公開維護關係的生態工具

Vesper2026 維護這個 MIT 授權工具與網站，與相關的 Eqvero、KolmoPDF、KomoPDF 生態屬同一維護團隊。本網站不是第三方獨立背書。

Python CLI 讀取兩份本機 Markdown，不翻譯內容，也不傳送文件。靜態網站只提供教學與範例下載，沒有上傳處理、帳號或分析追蹤。頁面由 GitHub 託管；外部連結會連接各自服務。

KolmoPDF 在哪個步驟使用

KolmoPDF 的 PDF 轉 Markdown 服務可為 PDF 提供上游 Markdown。它是會上傳文件的獨立雲端服務；本開源對照工具不是其專有解析器、OCR 引擎或翻譯模型。

範例刻意省略一個章節。結構差異只提示人工覆核，不直接證明譯文錯誤。
