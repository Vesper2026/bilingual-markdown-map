關於雙語對照工具

Bilingual Markdown Map 是 Vesper2026 提供的 MIT 授權 Python 工具，按章節順序或明確索引映射比較兩份 Markdown。

從 PDF 文件開始

KolmoPDF PDF 轉 Markdown 可透過會上傳文件的雲端服務產生 Markdown；之後再用本機工具對照兩份文件，找出遺漏章節與非正文物件。

差異代表什麼

範例刻意省略圖片與一個章節。結構差異提示人工覆核，不是翻譯品質分數。CLI 不翻譯或傳送文件。
