01 / 可重現教學

不比對字面翻譯，找出雙語 Markdown 的結構遺漏

用兩份合成文件與本機索引映射，找出缺少的圖片和未配對的結果章節。

作者 Vesper2026首發 2026-11-03更新 2026-11-04

翻譯後的標題通常不會使用相同字詞。直接做文字差異比對，即使結構完整，也會把每個標題標成變更。這個練習先按章節位置配對，再檢查少數非正文物件。

執行雙文件範例

準備 Python 3.10 或更新版本，在儲存庫根目錄執行，不必安裝套件。

python bilingual_map.py examples/source.md examples/zh-Hant.md --output examples/output

英文練習文件有 Methods 與 Results。Methods 包含圖片目標、連結、Python 程式碼圍欄及獨立公式區塊。繁中練習文件包含「方法」、相同連結、程式語言及公式數量，卻刻意省略圖片與結果章節。圖片目標只是測試用的文字引用，並非可下載的圖片成品。

1 section pairs; 1 source / 0 target unpaired. No semantic scoring.

查看已配對的章節

comparison.md 將原文索引 1「Methods」配對至譯文索引 1「方法」，待覆核欄位為 images；原文索引 2「Results」另列為未配對。JSON 報告保留各章節的起始行與物件清單，方便人工定位。

明確指定映射

加上 --map examples/mapping.json，即可使用明確配對 [[1,1]]。若完整譯文調換兩個章節，則可用 [[1,2],[2,1]] 指定真正對應關係。每個索引只能出現一次。接受順序比對前應先看標題，因為中間漏掉一節，後續配對就可能整體錯位。

若資料由 PDF 開始， KolmoPDF 雲端轉換會上傳 PDF；本工具只對照之後的本機 Markdown。結構相同不表示句子翻譯正確。
